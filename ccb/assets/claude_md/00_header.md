## ccb-managed context

This block is maintained by [Claude Context Box](https://github.com/alter/claude-context-box).
It tells Claude how the project is organized and how to keep documentation in
sync. **Do not edit between the markers** — changes will be overwritten on the
next reinstall. Add your own rules above or below the markers.

- Architecture map: `PROJECT.llm` (auto-updated)
- Per-module interface: `<module>/CONTEXT.llm` (auto-updated)
- Skills installed: see `.claude/skills/ccb-*`
- Hooks installed: see `.claude/settings.json` and `.claude/hooks/`
